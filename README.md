Hospital ER Management Dashboard – Detailed Project Explanation
1. Project Overview
The Hospital Emergency Room (ER) Management Dashboard is a Power BI project designed to analyze emergency room patient data. It helps understand patient demographics, admission patterns, department referrals, waiting times, and patient satisfaction.
2. Tools Used
- Power BI Desktop – Dashboard creation and visualization
- Power Query – Data cleaning and transformation
- DAX – Calculations and KPI measures
- CSV Dataset – Hospital ER patient records
3. Key Business Questions
- How many patients visited the emergency room?
- What is the distribution of patients by gender and age?
- How many patients were admitted?
- Which departments received the most referrals?
- What is the average patient waiting time?
- How satisfied were patients with their experience?
4. Data Preparation
In Power Query, the main preparation tasks include:
- Checking and handling missing values.
- Converting admission dates into the correct date format.
- Verifying data types for age, waiting time, and satisfaction scores.
- Checking duplicate patient records.
- Reviewing the meaning of fields such as Patients CM before using them in KPIs.
5. Expected Business Benefits
The dashboard can help hospital management identify busy periods, compare department workloads, monitor waiting times, and understand patient satisfaction patterns. These insights can support operational improvements, although the dashboard alone does not establish the causes of delays or dissatisfaction.

Project Description
Hospital ER Management Dashboard | Power BI

Developed an interactive Power BI dashboard to analyze emergency room patient data, including patient demographics, admission status, department referrals, waiting times, and satisfaction scores. Used Power Query for data preparation and DAX measures for key performance indicators. Created interactive visualizations to identify patient visit patterns and support data-driven operational analysis.


“My project is a Hospital ER Management Dashboard developed using Power BI. The main objective was to analyze emergency room patient data and understand patient demographics, admission patterns, department referrals, waiting times, and satisfaction levels.

I used Power Query to clean and transform the data, created visualizations to compare different patient metrics, and used DAX to calculate KPIs such as total patients, admission rate, and average waiting time.

The dashboard helps users explore patient trends and identify areas that may need further investigation to improve emergency department operations.”
